# CSRSE 2026 experiment evidence manifest

This manifest links the numerical claims in the paper to executable code and machine-readable outputs. It documents software evidence and reproducibility; it does not claim calibration against real airport operations.

## Reproduction command

Run from the repository root:

```text
npm run experiment:paper-disruptions -- 42 20
npm run experiment:paper-disruptions -- 42 1
```

The first command executes 20 seeds (42--61) for five conditions, producing 100 formal runs. The second produces the detailed seed-42 matrix and verifies deterministic replay for all five conditions.

## Scope of the evidence

These records demonstrate that the reported values were generated by the repository's simulator and that the formal batch is repeatable under the same source tree, scenario, and seeds. They do not by themselves prove empirical validity, airport-data calibration, or correctness of every model assumption. Those require independent operational data and external validation.
